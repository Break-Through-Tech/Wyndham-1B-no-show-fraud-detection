# Wyndham dashboard frontend

Kaden’s original React dashboard, with Figma-specific Vite configuration removed for local development. The UI currently uses mock data; it is **not yet connected** to FastAPI.

From `dashboard_frontend` run:

```powershell
npm install
npm run dev
```

Open the local URL shown by Vite (usually http://localhost:5173). Keep the Python FastAPI server running separately when integrating.
